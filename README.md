# 属性对比台（Chrome 扩展）

对比 target 与 source 两个对象的属性：自动找出**相同属性**与**重复属性值**，
在输入框中高亮命中行，并把命中条目提取到结果框。

## 功能

- 四框界面：① Target 输入 / ② Source 输入 / ③ Target 结果 / ④ Source 结果
- 输入格式：每行一个属性 `属性名: 值`（中英文冒号都支持；无冒号的行视为属性名）
  - 兼容粘贴时带上的开头标签（`target:` / `source：`）
  - 兼容「裸属性 + 属性名:值」同行粘贴，如 `流行服飾/配件 色系:黑色`
- 自动实时对比（输入后 250ms 防抖）
- **属性名等价归一**：比较前先识别"同一个属性的不同写法"，避免误标：
  - **别名表**：`實際總長度`≡`總長度`、`胸圍實際寬度`≡`胸圍`、`色系`≡`顏色`
    （**独立维护在 `extension/aliases.js`**，加等价属性名只需改这一个文件，不用动逻辑）
  - **自动包含匹配**：一侧属性名包含另一侧（如 `主面料` ⊃ `面料`）自动视为同名
  - 归一后**同名同值 → 不标记**；同名但值不同 → 蓝
  - 例外：值相同但属性名完全无关（如 `數量: 2` vs `庫存: 2`）→ 维持现状（粉）
- 标记规则（**同名同值说明两边完全一样 → 不标记**）：
  - **同名但值不同**（跨对象）——重点标记，如 `色系: 黑色` vs `色系: Black Tones` → 蓝
  - 值跨对象重复（属性名可不同）→ 粉
  - 对象内部值重复（同一对象内值出现多次）→ 粉
- 高亮颜色：**蓝 = 同名值不同**；粉 = 重复值；完全相同的不标记
- 结果框自动收集命中条目并带规则徽章；点击条目跳转到输入框对应行并闪烁
- **复制差异清单**：一键复制所有「同名值不同」为 `属性名 / Target值 / Source值` 三列
  （Tab 分隔，可直接粘贴进 Excel/表格）
- **主流鞋码对照表**：页脚「尺码对照表」按钮展开，**成人/儿童切换**（胶囊标签）
  - 成人表（脚长mm / 欧码 / 美码男 / 美码女 / 英码UK，英码不分男女合为一列；
    以 Nike 等主流运动品牌官方尺码表为参考：美码女 ≈ 美码男 + 1.5）
  - 儿童表（脚长mm / 欧码 / 美码US(童) / 英码UK，US/UK 不分男女；
    以 Nike 官方儿童尺码表为参考：婴儿~大童 70–260mm，含半码，1Y 从 200mm 起；
    儿童码与成人码非同一刻度，勿混用；大童 7Y（≈260mm）与成人男码 US 7 同号衔接；
    建议实测脚长加 5–10mm 成长空间再选码）
  - 点击行可高亮对照；数据独立维护在 `extension/sizes.js`
- 一键清空；不持久化保存（关闭即清空）

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目的 **`extension/`** 目录
4. 点工具栏上的扩展图标打开侧边栏（需要 Chrome 114+）

> 若 Chrome 提示加载失败，把 `extension/` 目录复制到本地磁盘（如 `~/attr-diff-extension`）再加载。

## 目录结构

```
├── extension/            # Chrome 扩展本体（chrome://extensions 加载此目录）
│   ├── manifest.json     # 扩展清单（MV3、sidePanel、图标）
│   ├── background.js     # 后台脚本：点图标打开侧边栏
│   ├── sidepanel.html    # 侧边栏页面（四框布局）
│   ├── sidepanel.css     # 样式（高亮颜色、徽章、布局）
│   ├── sidepanel.js      # 界面逻辑（防抖对比、镜像高亮、结果框、跳转、清空）
│   ├── compare.js        # 纯对比逻辑（解析 + 规则 + 属性名等价归一），不依赖 DOM
│   ├── aliases.js        # 属性名等价别名表（独立维护，加等价词只改这个文件）
│   ├── sizes.js          # 主流鞋码对照表数据（独立维护，改尺码只改这个文件）
│   └── icons/
│       └── icon128.png   # 工具栏/扩展图标
├── tests/                # 自动化测试
│   ├── test_compare.js        # 对比逻辑单元测试（Node）
│   ├── test_dom_cdp.mjs       # 页面级端到端 DOM 测试（真实 Chrome 引擎，含截图）
│   └── test_extension_cdp.mjs # 扩展级验证脚本（受环境限制，见下）
├── scripts/
│   └── gen_icon.mjs      # 图标生成脚本（SVG → PNG）
├── docs/
│   └── ui-preview.png    # 界面预览截图（测试自动生成）
└── examples/
    └── 示例数据.txt      # 可粘贴的示例数据（含预期效果）
```

## 测试

```bash
npm test                                  # 对比逻辑 + 页面级 DOM 测试
node tests/test_compare.js                # 仅对比逻辑测试
node tests/test_dom_cdp.mjs               # 页面级 DOM 测试（生成 docs/ui-preview.png）
node tests/test_extension_cdp.mjs         # 扩展级验证（无头模式，加载失败则 SKIP）
HEADLESS=0 node tests/test_extension_cdp.mjs  # 扩展级验证（有头模式）
```

## 已知事项

- 升级后需在 `chrome://extensions` 对该扩展点「重新加载」
- 本环境的 Chrome 152 通过命令行 `--load-extension` 加载扩展不生效
  （连极简扩展都失败，与代码无关），因此扩展级自动化验证无法进行，
  请以 `chrome://extensions` 界面手动加载为准。
- 无头 Chrome 不支持扩展加载，属于 Chrome 已知限制。
